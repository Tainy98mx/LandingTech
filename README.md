# NovaDev - Landing Page Tecnológica

Página web moderna y modular de una empresa de desarrollo de software, estructurada por componentes separados en carpetas individuales.

## Estructura por Carpetas

Cada sección contiene de forma independiente su archivo HTML, CSS y JavaScript:

- `navbar/`: Barra de navegación y menú móvil.
- `hero/`: Portada principal con animación de entrada GSAP.
- `servicios/`: Servicios ofrecidos con animación al scroll.
- `tecnologias/`: Explicación sencilla de qué crea cada tecnología (HTML5, CSS3, JavaScript, React, Node.js, Bases de datos, APIs de pago, Git).
- `estadisticas/`: Cifras y métricas clave de la empresa.
- `proyectos/`: Casos de éxito con animación al scroll con GSAP.
- `calculadora/`: Calculadora interactiva sencilla (Cantidad de páginas x $800 = Costo estimado, modificando el elemento por su ID).
- `contacto/`: Formulario funcional con confirmación de envío.
- `footer/`: Pie de página con enlaces y datos de contacto.
- `estilos-globales.css`: Paleta de colores claros y estilos compartidos.
- `index.html`: Archivo principal que integra las secciones sin congestión.
